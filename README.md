# Taschenrechner

Ein einfacher Taschenrechner in Python für die Grundrechenarten.  

## Funktionen

-Addition
-Subtraktion
-Multiplikation
-Division 

## Nutzung 

Programm starten mit : 

Pyhton main.py 

Danach im Menü auswählen, mit welcher Rechenart gerechnet werden soll.
Dann zwei Zahlen eingeben.
